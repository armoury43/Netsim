# NetSim screenshot assets

These screenshots are included in the source repository to make the first visit to the project more informative.

- `gui-basic-lan-verified.png` is a direct capture of the Tkinter application running the `basic-lan` scenario with the real CLI session and lab verifier reporting 10/10 checks passed.
- `gui-preview.png` at the `assets/` root shows the fresh starter workspace.
- The `cli-*.png` files present command/output transcripts captured by executing commands through the NetSim 0.1.2 runtime (`CliSession.execute_line`). They are presented in a consistent terminal-style frame for readability. Command output is produced by the project itself; the visuals are not claims of live network traffic.

NetSim is an in-memory educational simulator. The pictured ICMP, routing, ACL, and verification behavior stays inside the simulator.
